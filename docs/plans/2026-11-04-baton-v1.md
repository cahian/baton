# baton v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A supervisor that relays one goal across the Codex and Antigravity CLIs, stops each before paid credits, and finishes only on a passing verify command.

**Architecture:** A synchronous Python runner owns the loop. Vendor differences live in adapters behind one interface. A local gateway exposes this to OpenCode as one model; jobs run independently of the HTTP connection.

**Tech Stack:** Python 3.12, uv, standard library only, pytest, ruff.

**Spec:** `docs/specs/2026-11-04-baton-design.md`. Read it fully before any task: it holds the exact field names, thresholds, commands and outcome table.

## Global Constraints

- Python 3.12 managed with uv. No runtime dependencies.
- `threshold_pct`: codex 90, antigravity 90. `poll_s`: codex 15, antigravity 30. Limit read timeout 15 s. SIGKILL 10 s after SIGTERM.
- Unknown means stop: failed or unparseable safety data never allows an agent to run.
- Balances compare with `decimal.Decimal`, never float.
- Tests never call a real vendor and never read real credential files.
- No personal data, hostnames, account IDs, real paths or secrets in tracked files.
- Code, docs and commit messages in English.
- Every commit message ends with:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and
  `Claude-Session: https://claude.ai/code/session_01EgGzjmFAvVGv8vf25aLJ7B`
- Stage only the files the task touched. Run `uv run pytest -q` and `uv run ruff check .` before each commit, then `git push`.

## Review Focus

1. A limits read that returns non-JSON, an RPC error, a hung process, or missing `primary`: agent must be unavailable, never run. Owned by Task 3.
2. Cooldown timestamps already in the past, or `resetsAt` as null/0: agent becomes available rather than sleeping forever or crashing. Owned by Task 5.
3. Agent output with invalid UTF-8 or a 1 MB line: stream keeps working and guards keep firing. Owned by Task 2.
4. Runner restarted while an old agent group is alive: old group is killed before anything starts. Owned by Task 6.
5. Workdir that is not a git repository, or a gate command that does not exist: run continues, gate counts as not passed. Owned by Task 5.

### Task 5: Scheduler and runner

Add to `Store` from Task 1: `request_interrupt() -> None` and `take_interrupt() -> bool`.

**Files:** create `src/baton/scheduler.py`, `src/baton/runner.py`, `tests/test_scheduler.py`, `tests/test_runner.py`.

**Interfaces produced:**
```python
class Scheduler:
    def __init__(self, order: Sequence[str], adapters: Mapping[str, Adapter], store: Store, clock=time.time)
    def pick(self) -> Adapter | None
    def next_wake(self) -> float                     # epoch of earliest possible retry, at least now + 30
    def record(self, agent: str, result: RoundResult) -> None
    def snapshot(self) -> dict                       # per-agent state, usage and until, for state.json
def build_prompt(goal: Goal, gate_tail: str, notes: str, handoff: str, round_tail: str, resumed: bool) -> str
def run_gate(goal: Goal) -> tuple[bool, str]         # never raises
def snapshot_work(goal: Goal, n: int, agent: str) -> bool
def run_goal(goal: Goal, adapters: Mapping[str, Adapter], store: Store, clock=time.time, sleep=time.sleep) -> int
```
`record` applies the spec's outcome table: `limit` with no `until`: 15 min doubling to 60 min. `transient`: 1 min doubling to 30 min. `credit_guard` with no `until`: 30 min. `auth`: 30 min. `completed` and `timeout` clear that agent's backoff counters. An `until` of None, 0 or in the past counts as no known reset. `run_goal` returns 0 when the gate passes or a stop is honoured, and sleeps in steps of at most 5 s so stop is noticed. `.baton/` is created in the workdir and added to `.git/info/exclude` when that exists.
